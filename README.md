# sandbox

A playground for experiments, automations, and open-source exploration.

This is a GitHub Pages site for the `brownspacecow/sandbox` repository — a space for trying things out, testing automation workflows, and sharing small projects.

## Site

The site is built with Jekyll and hosted at https://brownspacecow.github.io/sandbox.

### Structure

- `index.md` — homepage with About, latest Daily Content, and Links sections
- `_config.yml` — Jekyll configuration (theme, permalinks, defaults)
- `_layouts/default.html` — shared page layout with navigation and footer
- `_posts/` — daily content posts (e.g. fantasy football injury updates and local Siouxland news)
- `assets/css/style.css` — shared stylesheet
- `assets/images/brown-space-cow.svg` — site logo

### Running locally

Jekyll is a Ruby gem. Install it, then serve the site:

```bash
gem install jekyll bundler
bundle install
bundle exec jekyll serve
```

The site will be available at http://localhost:4000/sandbox.
